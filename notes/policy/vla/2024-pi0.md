# π₀: A Vision-Language-Action Flow Model for General Robot Control

> Technical-report note · 技术报告笔记（不计入顶会核心目录）

## Metadata · 元信息

- **Authors**: Kevin Black et al., Physical Intelligence
- **Status**: arXiv technical report, 2024
- **Record**: [arXiv:2410.24164](https://arxiv.org/abs/2410.24164)
- **Track**: Foundation Models & VLA

## Core idea · 核心思路

π₀ places a flow-matching action generator on top of a pretrained vision-language model. It is trained on diverse data from single-arm, dual-arm, and mobile-manipulator platforms to produce continuous action chunks conditioned on images and language.

π₀ 在预训练视觉语言模型之上加入基于流匹配的动作生成器，并利用单臂、双臂与移动操作平台的多样数据，生成由图像和语言条件控制的连续动作片段。

## Pipeline · 流程

`images + language + robot state → VLM features → flow-matching action expert → continuous action chunk → robot`

## Reported evidence · 论文报告

- Evaluation covers zero-shot behavior after pretraining, language following, high-level VLM guidance, and skill acquisition through fine-tuning.
- Example tasks include laundry folding, table cleaning, and box assembly.
- The paper is evidence for a particular research system; it is not a formal top-conference acceptance record.
