# 分类说明：研究问题为主，关联标签为辅

本版结构为 **9 个一级方向 → 42 个二级子领域 → 126 个具体三级专题**。每个二级领域额外保留一个“待审专题”，总计 168 个末级入口。完整中英文名称见[分类图谱](../papers/taxonomy/README.md)。

## 怎么决定主要归属

以论文主要研究问题或贡献为准，而不是仅凭使用了 RL、Transformer 或某种机器人就决定一级位置。每个来源记录只有一条主路径；方法、形态、数据和关联主题独立维护，多标签可以组合筛选。自动规则只是一套可复现的近似判定，不能替代阅读全文。

- VLA 和通用策略放在策略学习；世界模型与模型驱动规划有独立入口。
- 普通夹爪抓取与多指灵巧手控制分开。
- 手部重定向与人形机器人全身动作迁移分开；同时涉及两者时使用关联主题。
- 主要贡献是数据引擎、仿真平台、基准或硬件时，主归属放在对应基础设施方向，而不是下游应用。

## 灵巧手重定向集中到哪里

“灵巧手、重定向与遥操作 → 灵巧手重定向”下分：

| 三级专题 | 核心问题 | 标题/摘要核查过的示例 |
|---|---|---|
| 运动学与姿态重定向 | 人手到机器人手的姿态、关键点、几何和关节映射 | GeoRT、AnyDexRT |
| 接触与功能重定向 | 保留手物接触、操作意图和任务功能 | DexMachina、TopoRetarget |
| 物理与动力学重定向 | 在仿真或动力学约束下产生可执行运动 | SPIDER、ReForce |

SPIDER 同时涉及跨形态和全身动作迁移：主要放在手部重定向，同时加全身重定向关联入口。EgoInfinity 主要贡献是数据生成引擎，放在数据方向，通过“手部重定向”标签能一起找到。HOGraspFlow 的平行夹爪重定向不作为灵巧手重定向。

以上是对现有标题/摘要的分类判断，不是对方法优劣、实验复现或全部正文的认证。跨分类入口见[重定向主题视图](../papers/topics/README.md)；主目录不会重复计数。

## 审核状态与不确定性

| 状态 | 含义 |
|---|---|
| reviewed | 有明确理由的标题/摘要核查例外；不代表全文精读 |
| rule-assigned | 由公开规则匹配归类；仍可能误分 |
| needs-review | 缺乏足够依据，或三级专题为待审；二级归属也可能暂定 |

没有依据的子领域使用该方向的暂定入口并标为待审，不表示确认属于那个二级领域。空分类保留，不为填满目录编造归属。

工作台可按审核状态筛选并展开依据；CSV 和 Markdown 导出保留状态、依据和标签。[待审清单](../papers/classification-review/README.md)按来源分页。
