## 重点调整

- 灵巧手重定向统一成为二级入口，不再分散在普通手部控制与遥操作的兜底分类里。
- DexMachina → 接触与功能重定向；SPIDER → 物理与动力学重定向；GeoRT、AnyDexRT → 运动学与姿态重定向。
- SPIDER 增加全身重定向关联；EgoInfinity 在数据方向主归属之外增加手部重定向关联。
- 世界模型与感知分开；硬件从灵巧手、仿真或其他应用类中独立出来。
- 重建双语首页、方向目录、全部末级目录及交互筛选。旧生成分类页已替换，可从 Git 历史恢复。
- 添加方法、形态、数据和关联主题筛选；分享链接和导出保留选择与分类证据。
